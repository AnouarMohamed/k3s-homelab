# Security

This is a public description of my private homelab. Do not open an issue containing a
domain, address, credential, recovery share, kubeconfig, or unredacted screenshot.

Report a suspected repository vulnerability privately through the GitLab project
security contact. I will assess exposure, rotate affected credentials, and publish a
redacted incident record when safe. This repository makes no availability commitment
and exposes no general-purpose hosted service.

The intended boundary is documented in
[`docs/security/public-surface.md`](docs/security/public-surface.md). Runtime status is
never inferred from manifests; see [`docs/STATUS.md`](docs/STATUS.md).
