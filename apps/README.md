# Applications

This directory contains Homelab Sentinel plus the private Vaultwarden, Homepage, and
Uptime Kuma workloads. Each production application uses a Kustomize overlay and is
generated by the restricted Argo CD ApplicationSet. Sentinel also has staging and
digest promotion because it is the repository-owned release artifact.

GitHub Actions publishes the complete declarative source for Homepage, Keycloak,
Sentinel, Uptime Kuma, Vaultwarden, and whoami as separate, signed OCI artifacts under
`ghcr.io/anouarmohamed/homelab-<name>-deploy`. Sentinel's owned API and worker images
remain separate packages built and promoted by the authoritative GitLab pipeline.
